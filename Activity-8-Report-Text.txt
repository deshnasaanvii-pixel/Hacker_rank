REFLECTION

This activity helped me understand how algorithm choice affects both execution time and memory usage. While solving Diagonal Difference, I learned that both diagonal sums can be calculated in one traversal instead of using separate passes. Dynamic Array introduced the use of vectors and the XOR operation to select sequences efficiently. Time Conversion strengthened my understanding of string indexing and conditional logic. Compare the Triplets showed how a simple fixed-size comparison can be implemented directly without unnecessary data structures. Sparse Arrays demonstrated the practical advantage of frequency mapping: storing each string count once avoids repeatedly scanning the complete input list for every query.

A major optimization lesson was to avoid repeated work. When a problem asks many queries about the same data, preprocessing or frequency counting can reduce the amount of computation. I also practiced identifying complexity before writing code, which makes it easier to choose suitable data structures. These problems improved my confidence in writing concise C++ solutions and documenting their time and space requirements. Integrating the solutions into GitHub also showed me how coding practice can be organized into a portfolio that can be reviewed by others.
